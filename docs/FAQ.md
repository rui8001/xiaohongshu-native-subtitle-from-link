# FAQ

## 为什么视频有字幕文件仍然不能做？

因为最终图片保留的是画面里的原生字幕。外部字幕只能帮助定位，不能替代已经烧录在画面中的文字。

## 必须固定六张或八张吗？

不必须。一张长图常见为六到八个不同字幕帧，但完整语义优先；可以更少或更多，只要主画面仍有足够空间。

## 为什么发布 ZIP 不含总览图和 manifest？

总览图与 manifest 属于质检材料。发布包故意只放编号 JPG，避免把内部检查文件误发到平台。

## 可以自动登录小红书并发布吗？

本 Skill 默认只准备草稿产物。登录、账号访问和公开发布都是独立授权，不会因为用户给了视频链接就自动执行。

## 下载失败怎么办？

如果普通公开访问不可用，请用户上传本地文件。不要使用 Cookie 绕过访问控制，也不要把 Cookie 写进 Issue 或仓库。
