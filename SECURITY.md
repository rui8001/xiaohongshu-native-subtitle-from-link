# Security, privacy, and rights

Do not report or commit real API keys, cookies, login URLs, account exports, private videos, unpublished media, personal paths, or production outputs.

Replace source material with synthetic video and subtitle data. For a sensitive disclosure, use GitHub's private security-reporting option rather than opening a public issue.

A user-provided link does not prove download or republication rights. This Skill must not bypass login, payment, geographic, DRM, or other access controls. It prepares drafts and never grants account access or publication authorization.
