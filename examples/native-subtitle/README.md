# 合成示例格式

这里的 manifest 和 JSON3 都是人为编写的格式示例，不来自真实账号或视频。

- `manifest.json` 中每个 `images` 项对应一张独立长图。
- `times` 必须严格递增，并应落在每句可见字幕的稳定中段。
- `sample.json3` 可以运行 `json3_to_timeline.py`，验证时间线转换。
- JSON3 顶层必须包含 `events` 数组；有字幕文字的事件必须提供非负整数 `tStartMs`、`dDurationMs`（单位毫秒，允许零）。不接受数字字符串、布尔值或小数，也不自动修正负数。没有文字的窗口/样式事件会跳过。
- 非法事件会在写入时间线前报错，错误只说明事件位置和字段要求，不回显字幕正文；修正输入后可重新运行。
- 仓库没有附带真实视频，以避免版权、肖像、账号和再分发问题。

若要试运行渲染器，请使用自己制作、允许公开处理并带内嵌字幕的短视频。
